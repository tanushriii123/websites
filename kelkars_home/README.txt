KELKAR'S HOME — WEBSITE STARTER

Files
- index.html: page structure and content
- style.css: layout, colours, responsive design
- script.js: mobile menu, current year, back-to-top button, and demo enquiry interaction

Run locally
1. Download and extract the ZIP.
2. Open the kelkars_home_website folder in Visual Studio Code.
3. Open index.html in your browser, or use the Live Server extension in VS Code.
4. Replace sample contact details and illustrative project images with verified studio details and actual work.

Important before publishing
- The enquiry form is a front-end demo. It does not save submissions to a database or send them to the architect.
- In script.js, replace hello@kelkarshome.example with the real business email. A mailto link relies on the visitor having an email app configured and is not a dependable production form.
- For reliable client enquiries, connect a secure backend/API or a reputable form service. Add spam protection and a privacy notice before collecting real personal information.
- Add the real studio address, business phone, social links, service area, qualifications, and any relevant professional registration details.
- The portfolio images are remote Unsplash examples used as visual placeholders, not projects completed by Kelkar's Home.
- Google Fonts and the sample images require an internet connection.
- Have all project claims, professional credentials, scope, fees, and legal/approval responsibilities reviewed for accuracy before going live.
